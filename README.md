# ORANGE BOJONG RAYA - WEBSITE & PWA

Aplikasi web resmi komunitas **Orange Bojong Raya Sub Korwil Cengkareng** berbasis Progressive Web App (PWA).

## 🚀 Fitur Utama
1. **Jadwal & Hasil Pertandingan Persija Jakarta**:
   - Countdown Timer untuk *Next Match* (Dewa United vs Persija Jakarta).
   - *Fixtures & Results* BRI Super League 2026/2027.
   - Tabel Klasemen Liga lengkap dengan form 5 laga terakhir.
   - Detail Hasil Laga (*Match Detail*): Scoresheet, Info Stadion, Lineups, & Statistik Pertandingan.
2. **Manajemen Admin**:
   - Kelola Galeri Foto Kegiatan (Nobar, Baksos, OBR Sport).
   - Kelola Struktur Pengurus Organisasi (Pengurus Harian, Humas, Korlap, OBR Sport).
3. **PWA (Progressive Web App)**:
   - Dukungan Mode Standalone & Installation ke Layar Utama Smartphone dengan Logo Resmi OBR.
4. **Footer Navigasi Interaktif**:
   - Direct router mapping sesuai dengan struktur navigasi persija.id.

## 📦 Cara Upload ke GitHub
1. Extract file `.zip` ini.
2. Buka terminal/Git Bash di folder ini.
3. Jalankan perintah berikut:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - Orange Bojong Raya Web PWA"
   git branch -M main
   git remote add origin https://github.com/USERNAME/NAMA-REPO.git
   git push -u origin main
   ```
4. Aktifkan **GitHub Pages** di menu `Settings -> Pages -> Branch: main / root` untuk publikasi gratis.
